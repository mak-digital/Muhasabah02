# Dhikr input UX

## Scope

Check-in rows for post-fard Salah Adhkar, Morning Adhkar, Evening Adhkar, and Other Adhkar use the same performed list.

## Layout

Each row is a compact expandable tile. Tapping the row opens the full **Dhikr performed** list. The performed count sits top-right of the row title. Hint under the title: `Tick the box(s) and change the respective count to actual`. Each line has a checkbox and a count box sized for three digits (33, not 033). **Verified wording available** opens the matching Learn & Practice item(s) with the Arabic face and − A + size controls; Close returns to this check-in without losing the recording in progress. Ticking a line focuses and selects that count. A typed count is remembered as that item’s default next session. A heading checkbox selects or clears all. Unticked stays not recorded. Count is a notice, not a target.

Post-fard lists the verified post-prayer set on each of Fajr, Dhuhr, Asr, Maghrib, and Isha. Morning and evening list their verified Learn & Practice sets. Other Adhkar keeps General, Gratitude, Travel, Personal, and Other Adhkars as separate rows.

Save remains the existing check-in Save control and writes the whole day.

## Responses

A tick records practised. Unticked stays not recorded, not “not today.”

Personal (and personal travel dua) records a topic. The words of the dua are not required.

## Source

Verified wording opens Arabic, transliteration, meaning, and citation. Topic rows may show **Related wording available** for a nearby Learn & Practice item. Pending rows have no formula link. The performed-list heading row (Dhikr performed / Count) uses a light wash on every such page.

## Home / Today sheets

The same editor is used when a Home or Today cell opens a Dhikr row. Quick Tap on those mix rows also opens this list; it does not cycle a generic mark.
