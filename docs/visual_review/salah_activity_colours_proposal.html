Salah activities — list, optional colour legend

Mock only. Current Home / Progress mark colour stays the default. Optional activity colours live under Settings → Application → Activities. Colour names a recorded choice. It is not a grade.

Assessment
  • Keep the list. Nine of the ten labels are already the Salah check-in catalog. Add Excused after Prayed alone on time. Keep Other last.
  • Optional colour legend is possible without rewriting saved days. Check-in already stores the activity id. Home and Progress today collapse those ids to on time / late / missed / unanswered and paint every mark in the shared Salah colour.
  • Default stays as now. Shared mark colour, filled / outline / missed / unanswered. Domain wash still names the card, not the activity.
  • Settings → Application → Activities is the right home for the option. Same section as appearance and Domains. Not a Home control. Not a score.
  • Do not ship the ranking captions. “Excellent”, “Urgent Attention”, “Highest priority for corrective action”, “Preserve and maintain” prescribe and rank. Muhasabah may describe what was recorded. It does not tell the person what to do next.
  • Do not treat colour as a spiritual scale. Blue is not better than amber. Optional colours only help tell congregation-on-time from prayed-late at a glance.
  • Small congregation keeps light green #66BB6A and the same round mark as every other Salah choice.
  • Excused must never become missed. Other should not keep mapping to late. Both stay recorded observations.
