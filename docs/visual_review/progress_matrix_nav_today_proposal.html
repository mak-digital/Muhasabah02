Proposed Progress matrix — week arrows, today, future

Visual proposal only. Not yet in the app. Applies to every 7-day domain matrix (Salah, Qur’an, Dhikr, Fasting, Family, Charity, Hadith). 30-day and 90-day stay as they are unless you say otherwise. Device local calendar decides today and future. Missing is not missed. No scores.

Proposed behaviour
1. Each matrix has ← and → beside its title. They move that domain’s 7-day window to the previous or next week. The subtitle follows: (for the week starting on Date). Right arrow is quiet when the window already includes future days only if you prefer to lock “next” when the whole week is after today — this mock still allows peeking at next week.
2. The current local day is a light-yellow row. Marks on that row stay tappable so the person can add or update that day’s record (same cell sheet as Home).
3. Future days (after today on the local calendar) show empty marks at low contrast and are not tappable. Past days and today stay active.
4. Yellow is a calendar cue, not a rank. Colour of the filled/outline mark still identifies the domain.
