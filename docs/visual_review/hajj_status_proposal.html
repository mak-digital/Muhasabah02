Hajj — standing status, user-owned

Hajj is a pillar, like zakat. It should appear in the app so the user can name whether it is due, not due, in preparation, or already performed — and then ponder and prepare on their own terms. The app must not calculate ability, set a deadline, or treat unanswered as missed.

Keep (parallel to Zakat). User chooses the status. No amounts, no visa checklist as a score, no “overdue”. Unanswered is empty, not a failing. Mix can include Hajj like the zakat mix key. Daily preparation, if shown, is engagement / not today / unanswered — same as Fasting rows.

Do not. Fatwa engine, istita‘ah calculator, age/wealth auto-due, Dhul-Hijjah countdown as a command to travel, shame for not having gone, conflating Umrah with the fard status, or a week of seven “Due” diamonds as if Hajj were a daily fard like Salah.

Why not a Zakat-style week of diamonds for the pillar itself

Zakat status is already a standing meaning painted across the week (due / planned / paid). That is a bit awkward for an annual duty; it would be worse for a once-in-a-lifetime pillar: seven identical “Performed” marks every week forever. Hajj’s pillar state should live as one standing record (like Hadith memorisation focus). A daily row is only for noticing preparation on a given day, and only while the user has named it due or in preparation.

Recommended marks

Status Meaning (user-owned) Mark
Not recorded No claim yet. Not “you skipped Hajj”. Empty
Not due The user does not currently hold Hajj as due (ability, timing, or circumstance as they see it). Dash — same language as zakat “not applicable”
Due The user names Hajj as due. The app does not verify this. Filled diamond (reuse zakat Due)
Preparing Saving, health, learning rites, travel — noticed as preparation, not a progress bar. Half diamond (reuse zakat Planned)
Performed The user records that the fard Hajj has been performed. Filled diamond with a quieter chip, not a trophy
Not applicable User’s own exclusion (e.g. they do not take this on). Same humility as zakat N/A. Dash

Optional later, not in this first cut: a separate Umrah row (nafl), or “repeat Hajj”. Do not fold those into the fard status.

Where it lives

Not on Charity. Charity is giving (infaq, zakat). Hajj is pilgrimage. Treat Hajj as its own optional Home card — same opt-in as Fasting — with a standing status at the top and, when Due or Preparing, one week row for “Noticed preparation”. Mix catalog key hajj. Storage: standing status in prefs (not a tenth recordable field); daily preparation in homeTraces.
