Suggested optional factors (dropdowns)

Visual proposal only. Same layout as the approved check-in dropdowns: domain CAPITAL bold, row name bold, value indented, lists A–Z. Factors stay optional provenance. They are never causes, scores, or completion.

Suggestion
  1. Keep one main dropdown for the activity (already implemented).
  2. Show factor dropdowns only after that main choice is recorded — not when it is unanswered.
  3. Split factors into two named groups, never mixed in one list:
    • Helping factors — support / enabling conditions you noticed
    • Distracting factors — challenges / interruptions you noticed
  4. Which group appears depends on the main selection (table below).
  5. Each visible group is one A–Z dropdown, default Not recorded (optional, skippable).
  6. One choice per group for now, so the screen stays uncrowded. Multiple chip-picks are not shown.
Main inputHelping factorsDistracting factors
No answer recorded / Unanswered / Not recorded Hidden Hidden
Recorded engagement, prayed on time, congregation, performed Shown Hidden
Recorded as not done, missed, not performed, no activity Hidden Shown
Late (Salah only: prayed late, joined congregation late, made up later) Shown Shown
