Proposed check-in data entry (dropdowns)

Visual proposal only. No app code in this file. Native lists below are the current activity labels, sorted A–Z. Missing / unanswered stays a valid choice. Colour still identifies the domain, not rank.

Layout rules in this mock
1. Domain title: CAPITAL, bold (SALAH, QUR’AN, DHIKR…).
2. Prayer / row name: kept as written, bold (Fajr, Recitation, Morning Adhkar).
3. Chosen value sits in a dropdown, indented from the left to show it is the next level under that name.
4. Dropdown options are alphabetical. Default shown here is “No answer recorded” / “Unanswered” / “Not recorded” as today’s empty state.
