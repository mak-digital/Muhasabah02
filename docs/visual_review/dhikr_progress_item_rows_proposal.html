Proposed Dhikr Progress — item rows × weekday columns

Review only. Not implemented. Current 7-day Dhikr Progress uses WeekMatrixBoard: each row is a day, each column is a Dhikr item (Faj / Dhr / … or vertical Mor-Adk). That is the reverse of Home Salah and Qur’an Journey, where rows are items and columns are weekdays.

Proposed 7-day layout (Dhikr Progress only in this step)
1. Keep the three bands: Post-fard Salah Adhkar, Morning and evening, Other remembrance.
2. Rows = the stored items in that band (Fajr … Isha; Morning Adhkar, Evening Adhkar; General … Other).
3. Columns = the calendar week, following first-day-of-week preference (here Monday first).
4. Header shows weekday letter and date number, as on Home. Today keeps the pale yellow halo. Future days stay inactive. Week ← → stay on the band title.
5. Marks unchanged: filled = recorded engagement, solid outline = recorded as not done, dashed = not recorded. Missing is not missed. Colour names Dhikr, not rank. No scores.
6. 30-day and 90-day stay one calendar per row unless you say otherwise.
7. Salah / Fasting / Charity 7-day Progress still use day-as-row. This mockup does not change them.
8. Full-domain Dhikr Home reuses this item×day grid (like Akhlaq). Title opens check-in.
