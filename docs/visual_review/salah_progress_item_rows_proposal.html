Proposed 7-day layout (Salah Progress only in this step)
1. Reverse the grid: rows = prayer names; columns = the calendar week (letter + date), following first-day-of-week preference.
2. Three boards, matching Home: Obligatory Salah (Fajr, Dhuhr, Asr, Maghrib, Isha), Friday Prayer (Jumu‘ah), Voluntary Prayers (Tahajjud, Ishraq).
3. Jumu‘ah is Friday-only. Other weekdays stay blank, not unanswered and not missed.
4. Marks unchanged: filled = on time / performed, solid outline = late / not performed (voluntary), slash = missed, dashed = not recorded. Today halo is a pale disc 1.5 mark-strokes larger than the circle (no cell wash). Future days inactive. Week ← → on each band. Page legend stays above the boards, not on Voluntary Prayers.
5. Colour names the domain (and Friday band wash). Shared mark colour by default. Not a spiritual score.
6. 30-day and 90-day stay one calendar per obligatory prayer unless you say otherwise. Friday and voluntary would join those longer views only if you ask.
7. Qur’an / Fasting / Charity 7-day Progress stay as they are in this step.
