Proposed General Dhikr input — performed list

For approval. Not implemented. Productivity and Hajj stay on their own patterns. Other worship domains follow the existing check-in concept: a named row, then the input for that row. Post-fard Salah Adhkar already does this (row title Fajr, then the remembrance list). General Dhikr should do the same: tap the row, open the performed list. Do not title a sheet “Add a General Dhikr activity”.

Proposed behaviour (General Dhikr only in this mockup)
1. Check-in still shows the row title General Dhikr under Other remembrance, like Fajr under Post-fard Salah Adhkar.
2. One tap opens Dhikr performed — the full list, not an empty “add another” picker.
3. Each line has a checkbox (this was involved) and a count box sized for three digits. The shown number is ordinary (33, not 033).
4. Hint copy: Tick the box(s) and change the respective count to actual. Ticking a checkbox moves focus to that line’s count and selects the number so typing replaces it.
5. A changed count is remembered as that item’s default the next time this list opens. It is personal habit, not a prescribed target.
6. The heading checkbox selects or clears all lines.
7. Tick as many lines as match the day. Unticked stays not recorded, not “not today”.
8. Count is a notice of how many times, not a target, reward, or score.
9. Save stays the existing check-in save. No extra add-flow copied from Productivity.
