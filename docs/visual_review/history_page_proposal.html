Manage past check-ins — layout proposal

Accepted and implemented. History tab: housekeeping of saved days. Distinct from Recorded days (read-only Historical Reflection). No scores. Removal is not forensic erasure.

What is hard to read today
  • Each saved day is a bulky card. 120 sample days become a long stack of identical tiles.
  • The subtitle “8/10 recordable fields answered” looks like a score or completion grade.
  • Remove is only on long-press, with no visible control, so housekeeping is easy to miss.
  • The page does not say how it differs from Recorded days.
Proposed
  1. One short guard: tap to edit; remove from the day menu. Not a score.
  2. Optional All / 30 days / 90 days is a view filter only — records are not rewritten.
  3. Weeks as one grouped list: weekday badge, date, “Tap to edit”, Sample pill, ⋮ menu.
  4. ⋮ opens Edit / Remove. Long-press can still remove. Confirm copy stays honest (not forensic erasure).
Recorded days keeps the calendar of saved vs empty. This page lists only days that already have a check-in.
