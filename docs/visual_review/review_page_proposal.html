Review page — layout proposal

Accepted and implemented on the Review tab. Colour still identifies domains; counts describe what was recorded. No scores, ranks, streaks, or heatmaps. Missing is not missed.

What is hard to read today
  • Seven identical white “Progress” rows come first, so the period facts sit below the fold.
  • Domain colour (the language used on Home) is unused, so Review feels like a settings list.
  • Recorded days and Recognition sit in the same stack as Salah/Qur’an, mixing “open a calendar” with “understand this period”.
  • The SEE → PONDER → EXPLORE order from the product spec is reversed: explore links, then facts, then the narrative.
Proposed reading order
  1. Choose the window — 7 / 30 / 90, with the date range under the chips.
  2. See the period — recorded vs unanswered days, then a two-column domain mosaic.
  3. Explore — tap a domain wash to open that Progress calendar (same destinations as now).
  4. Look closer — Recorded days and Recognition, visually quieter.
  5. Ponder, then respond — the existing descriptive narrative, then Add a response.
