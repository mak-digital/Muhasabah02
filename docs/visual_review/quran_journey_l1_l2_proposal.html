Recommendation if we implement this.
  • Keep four independent rows. Do not collapse the week to “highest stage only.”
  • Keep row order as you listed (Applied at the top) if you want a ladder. If you want a journey, flip it so Engaged is first. Ladder vs journey is the one product choice.
  • Put L1 then L2 in a bottom sheet, not a dropdown clipped to the circle. Same lists can remain on the full check-in.
  • Unanswered stays a dotted empty mark. None is an explicit “not this stage today” (pale ring, no letter).
  • Letters inside the ball are feasible. Understanding does not need a square if the letter carries L2.
  • R / M / T reuse is acceptable because colour is L1. Do not put letters on unanswered marks.
  • Storage can still map onto the existing seven dimensions (no schema bump): Engaged R/L → recitation; M → memorisation; V → revision; Understood T/M → meaning; F → tafsir; Reflected → reflection activities; Applied → conscious application activities.
  • Still not a score. Applied is “I recorded this kind of application,” not proof of improvement.
