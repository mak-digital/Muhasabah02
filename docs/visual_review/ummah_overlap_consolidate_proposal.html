Proposal #3 — Community & Ummah vs Salah, Huquq, Charity, Family

Visual review only. No app code has changed. Strike-through marks the service row that would leave Ummah Home, check-in, and Progress. The masjid row stays, with a clearer name so it is not a second Jumu‘ah. Stored ummah.communityService marks would not be deleted.

Agreed direction
  1. Salah owns the fard: on time / late / missed, and Friday congregational Jumu‘ah.
  2. Ummah owns service beyond the household that is not a salah status and not a sadaqah channel: earth as a trust, the oppressed, unity, dua for the Ummah, da’wah by character.
  3. Relabel masjid: Masjid class or gathering (not the fard). Same storage key.
  4. Hide Served beyond myself — Huquq neighbours, Charity community, and Family sick care already cover help to a person.
  5. Keep da’wah by character, with copy that it is character, not Akhlaq’s full virtue list.
  6. Do not auto-fill Salah, Huquq, or Charity from Ummah, or the reverse. Masjid attendance stays private, not a public check-in.
